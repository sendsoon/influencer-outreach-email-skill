# influencer-outreach-email-skill

**English** | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

Drafts copy-paste **Subject + body** for brand collaboration with overseas creators (YouTube, Instagram, TikTok, and similar).

**What it writes**

- Cold outreach: paid collab, product seeding, affiliate, first step of an ongoing deal, or a note to the manager / MCN
- If there is no reply: a second follow-up, then a closing note (max three emails per thread)
- Terms: deliverables, window, fee, usage rights
- Sample-shipped notices with tracking
- Replies after they write back: thank them first, one ask per email; if they have not quoted and there is no authorized budget, request a media kit / rate card before a brief; after a quote, hold or lock terms — never invent a counter-offer; after a clear no, a short thank-you and stop

## Install

```bash
npx skills add sendsoon/influencer-outreach-email-skill
npx skills update influencer-outreach-email-skill
```

## Example

**Input**

```
Brand: SendSoon — overseas EDM, typically cheaper than SendGrid / Klaviyo
Creator: Arun Maini, YouTube “Mrwhosetheboss” (@Mrwhosetheboss), ~22.8M, tech reviews
Watched: Google Pixel 11 Hands on — The Phone Crisis Begins; the “29% faster wireless charging” applies only to the smaller Pro, the XL is 17% in the small print
Collab: paid dedicated integration + affiliate
Recipient: Arun
Fee: USD 100–500
Commission: 10%, 30-day cookie
CTA: short reply
Brand URL: https://sendsoonai.com/
Sender: Charles Zhou, Partnerships, SendSoon, charles@mail.sendsoonai.com
```
